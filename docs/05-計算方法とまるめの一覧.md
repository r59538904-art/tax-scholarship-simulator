# 計算方法と端数処理（まるめ）の全一覧

**対象**：住民税・所得税・国民健康保険・JASSO奨学金 判定シミュレーター
**作成日**：2026年8月15日
**実装**：`assets/calc.js`（計算）＋ `assets/data.js`（税制データ）

このサイトが使っている計算式と端数処理を、**すべて**書き出したものです。
自治体の通知書や確定申告書と数字が合わないときは、この表と突き合わせれば
どこで差が出たか特定できます。

記号の意味：

| 記号 | 意味 |
|---|---|
| ⌊x⌋ | 切り捨て（`Math.floor`） |
| ⌈x⌉ | 切り上げ（`Math.ceil`） |
| ⌊x⌋<sub>1000</sub> | 1,000円未満切り捨て |
| ⌊x⌋<sub>100</sub> | 100円未満切り捨て |

## 0. 端数処理の一覧（最初に見るところ）

税額計算のズレはほぼ全部ここから出ます。**上から順に、計算の流れどおり**に並べています。

| # | 対象 | 端数処理 | 根拠 |
|---|---|---|---|
| 1 | 入力値 | 負の数・数値でないものは **0** として扱う | 損失は「繰越控除」欄で入力する仕様のため |
| 2 | 給与収入 | 1円未満切り捨て | — |
| 3 | 給与所得（190万円超〜660万円未満） | **収入÷4を1,000円未満切り捨て**してから率を掛ける | 所得税法別表第五（4,000円刻みの表） |

| 6 | 所得金額調整控除（子ども等） | **1円未満切り上げ** | 国税庁 No.1411 |
| 7 | 退職所得金額 | 1円未満切り捨て | — |
| 8 | 勤続年数 | **1年未満切り上げ** | 所得税法施行令69条 |

| 10 | 地震保険料控除（住民税の1/2） | **1円未満切り上げ** | 同上 |
| 11 | 医療費控除 | 1円未満切り捨て | — |

| 15 | 山林所得の5分5乗 | **5分の1にした額に追加の丸めはしない** | 所得税法89条（そのような定めがない） |
| 16 | 分離課税の所得税 | ⌊課税標準×税率⌋ | — |

| 18 | 所得税の年税額 | **100円未満切り捨て** | 国税通則法119条 |
| 19 | 住民税の所得割（総合・山林） | 市町村分・道府県分をそれぞれ ⌊課税標準×税率⌋ | — |

| 21 | 調整控除 | 市町村分・道府県分をそれぞれ ⌊基礎額×率⌋ | 地方税法37条 |

> ここを間違えると最大で数百円ずれます。

## 1. 所得の計算

### 1.1 給与所得（所得税法別表第五）

まず収入を1円未満切り捨てし、`A ＝ ⌊収入 ÷ 4⌋`<sub>1000</sub> を作ります。

| 給与収入 | 給与所得 |
|---|---|
| 最低保障額以下 | 収入 − 最低保障額（0円を下回らない） |
| 最低保障額超 〜 360万円未満 | **A × 2.8 − 80,000円** |
| 360万円 〜 660万円未満 | **A × 3.2 − 440,000円** |
| 660万円 〜 850万円未満 | ⌊収入 × 90％⌋ − 1,100,000円 |
| 850万円以上 | 収入 − 1,950,000円 |

最低保障額と、それが適用される収入の上限：

| 年分 | 最低保障額 | 適用上限 |
|---|---|---|
| 令和7年分（2025年） | 650,000円 | 1,900,000円 |
| 令和8年分（2026年） | 740,000円 | 2,200,000円 |

**`A` を作るときの1,000円未満切り捨てが要点です。** これが法定表の4,000円刻みを再現します。
省くと最大で数百円ずれます（名古屋市の公式計算例：給与収入5,505,000円 → 給与所得3,963,200円。
率を直接掛けると3,964,000円になり、年税額が100円過大になります）。

```
A = ⌊5,505,000 ÷ 4⌋1000 = ⌊1,376,250⌋1000 = 1,376,000
給与所得 = 1,376,000 × 3.2 − 440,000 = 3,963,200円
```

#### 境目に「固定額の特例行」が要らない理由

旧制度（令和6年分以前・最低保障55万円）の別表第五には、**1,619,000円〜1,627,999円に
固定額の細かい行**（969,000円・970,000円・972,000円・974,000円）がありました。
最低保障が切り替わる収入が 1,625,000円 で、**4,000円の倍数ではなかった**ためです。

令和7年分・令和8年分は、切り替わる収入がどちらも4,000円で割り切れます。

| 年分 | 最低保障が切り替わる収入 | ÷4,000 | 特例行 |
|---|---|---|---|
| 令和6年分以前 | 1,625,000円 | 406.25 | **必要だった** |
| 令和7年分 | 1,900,000円 | 475 | 不要 |
| 令和8年分 | 2,200,000円 | 550 | 不要 |

そのため実装も特例行を持たず、切り替わる収入をそのまま帯の起点にしています。
この構造（①最低保障区間は1円刻みで連続 ②境目で段差なし ③境目から4,000円ごとの階段）は
`verify-calc.js` §1c で機械的に検証しています。

> ⚠️ **令和8年分の別表第五そのもの（国税庁「年末調整のしかた」に掲載）は、
> 例年9〜10月の公表です。公表され次第、上の構造と実際の表を突き合わせてください。**
> 現時点では改正内容（最低保障74万円・適用上限220万円）から構造を再現しています。

画面に出る「給与所得控除額」は `収入 − 給与所得` として逆算した額です。

### 1.2 公的年金等に係る雑所得（国税庁 No.1600）

**控除額**：

| 年金収入 | 65歳未満 | 65歳以上 |
|---|---|---|
| 最低保障の上限以下 | 600,000円 | 1,100,000円 |
| 〜410万円 | 収入 × 25％ ＋ 275,000円 | 同左 |
| 〜770万円 | 収入 × 15％ ＋ 685,000円 | 同左 |
| 〜1,000万円 | 収入 × 5％ ＋ 1,455,000円 | 同左 |
| 1,000万円超 | 1,955,000円 | 同左 |

最低保障の上限：65歳未満 **1,300,000円** ／ 65歳以上 **3,300,000円**

**公的年金等以外の合計所得による減額**：

| 年金以外の合計所得 | 控除額から差し引く額 |
|---|---|
| 1,000万円以下 | 0円 |
| 1,000万円超 2,000万円以下 | 100,000円 |
| 2,000万円超 | 200,000円 |

```
控除額 = min( max(0, 表の額 − 減額), 年金収入 )
雑所得 = ⌊ max(0, 年金収入 − 控除額) ⌋      ← 1円未満切り捨て
```

**最後の切り捨てが重要です。** 速算表は実質「収入×75％ − 275,000円」のような式なので
小数が出ます。小数のまま持つと、合計所得金額が非課税限度額とちょうど並んだときに
課税／非課税の判定が反転します。

### 1.3 事業所得・不動産所得・その他の所得

入力された**所得金額**（収入 − 必要経費）をそのまま使います。計算も丸めもしません。
負の値は0として扱うため、赤字は「繰越控除」欄で入力してください。

### 1.4 所得金額調整控除（措置法41条の3の3）

**① 子ども・特別障害者等を有する者等**

適用要件：給与収入が850万円超で、次のいずれかに当てはまる。
23歳未満の扶養親族がいる／本人が特別障害者／特別障害者である同一生計配偶者・扶養親族がいる。

```
調整額① = ⌈ ( min(給与収入, 10,000,000) − 8,500,000 ) × 10％ ⌉    ← 1円未満切り上げ
```

**② 給与所得と年金所得の双方を有する場合**

給与所得（①適用後）と公的年金等の雑所得が両方ある場合。

```
調整額② = max( 0, min(給与所得①後, 100,000) + min(年金雑所得, 100,000) − 100,000 )
```

②は**①を差し引いた後の給与所得**を使います（順序が決まっています）。

```
最終的な給与所得 = 給与所得 − 調整額① − 調整額②
```

### 1.5 分離課税の所得

入力された金額をそのまま使います（特別控除後の金額を入力する仕様）。

| 種類 | 所得税 | 復興税込み | 住民税 | 合計 |
|---|---|---|---|---|
| 土地建物等の短期譲渡（5年以下） | 30％ | 30.63％ | 9％ | **39.63％** |
| 土地建物等の長期譲渡（5年超） | 15％ | 15.315％ | 5％ | **20.315％** |
| 株式等に係る譲渡所得等 | 15％ | 15.315％ | 5％ | **20.315％** |
| 上場株式等に係る配当所得等 | 15％ | 15.315％ | 5％ | **20.315％** |
| 先物取引に係る雑所得等 | 15％ | 15.315％ | 5％ | **20.315％** |

### 1.6 山林所得

```
山林所得 = max( 0, 収入 − 必要経費 − 500,000 )      ← 特別控除50万円
```

### 1.7 退職所得

```
勤続年数 = max(1, ⌈入力年数⌉)                        ← 1年未満切り上げ

退職所得控除額 = 勤続20年以下 : max(800,000, 400,000 × 年数)
                 勤続20年超   : 8,000,000 + 700,000 × (年数 − 20)
                 障害による退職なら さらに +1,000,000

残額 = max(0, 退職金の収入 − 退職所得控除額)
```

残額から退職所得金額を出す方法は3通りです。

| 区分 | 退職所得金額 |
|---|---|
| 特定役員退職手当等（役員等で勤続5年以下） | **残額（2分の1にしない）** |
| 短期退職手当等（勤続5年以下）で残額300万円以下 | 残額 ÷ 2 |
| 短期退職手当等（勤続5年以下）で残額300万円超 | **1,500,000 + (残額 − 3,000,000)** |
| 上記以外 | 残額 ÷ 2 |

最後に1円未満を切り捨てます。

**住民税では退職所得を使いません。** 退職時に分離課税で徴収済み（現年分離課税）のため、
翌年度の住民税・非課税判定・扶養判定・奨学金判定・国保の軽減判定のいずれにも入りません。

### 1.8 合計所得金額と総所得金額等

このサイトが**最も厳密に分けている**ところです。

```
合計所得金額（繰越控除「前」）
  = 総合課税の所得 + 分離課税の所得 + 山林所得 + 退職所得（所得税のみ）

総所得金額等（繰越控除「後」）
  = 上記から繰越控除を適用した後の金額
```

| | 合計所得金額 | 総所得金額等 |
|---|---|---|
| 繰越控除 | 適用**前** | 適用**後** |
| 使う場面 | 住民税**均等割**の非課税判定／扶養・配偶者控除の判定／基礎控除・勤労学生控除の所得要件／調整控除の2,500万円判定 | 住民税**所得割**の非課税判定・課税標準／医療費控除の足切り／国保の軽減判定 |

株式の譲渡損失を繰り越していると「**所得割は非課税なのに均等割は課税**」「**扶養から外れる**」
が起こります。

### 1.9 繰越控除の適用順序

**① 上場株式等に係る譲渡損失**（引ける相手が決まっています）

```
株式等に係る譲渡所得等 → 上場株式等に係る配当所得等
```

この2つからしか引けません。先物や不動産譲渡からは引けず、引けなかった分は残ります。

**② 純損失・雑損失**

```
総所得金額 → 短期譲渡 → 長期譲渡 → 株式等譲渡 → 上場株式等配当 → 先物 → 山林 → 退職
```

## 2. 所得控除

すべて **1円未満切り捨て**で確定します（生命保険料・地震保険料は切り上げ後なので整数）。

### 2.1 金額をそのまま使うもの

社会保険料控除／小規模企業共済等掛金控除／雑損控除／その他の所得控除。
入力額をそのまま控除します。

### 2.2 生命保険料控除

**区分ごとの控除額**（一般・介護医療・個人年金の3区分それぞれ）：

新契約（平成24年1月1日以後）

| 年間支払保険料 | 所得税 | 住民税 |
|---|---|---|
| 〜20,000円（住民税は12,000円） | 全額 | 全額 |
| 〜40,000円（32,000円） | ⌈支払 × 1/2 + 10,000⌉ | ⌈支払 × 1/2 + 6,000⌉ |
| 〜80,000円（56,000円） | ⌈支払 × 1/4 + 20,000⌉ | ⌈支払 × 1/4 + 14,000⌉ |
| それ超 | 40,000円 | 28,000円 |

旧契約（平成23年12月31日以前）

| 年間支払保険料 | 所得税 | 住民税 |
|---|---|---|
| 〜25,000円（住民税は15,000円） | 全額 | 全額 |
| 〜50,000円（40,000円） | ⌈支払 × 1/2 + 12,500⌉ | ⌈支払 × 1/2 + 7,500⌉ |
| 〜100,000円（70,000円） | ⌈支払 × 1/4 + 25,000⌉ | ⌈支払 × 1/4 + 17,500⌉ |
| それ超 | 50,000円 | 35,000円 |

**新旧の両方がある区分**は、有利なほうを自動で選びます。

```
区分の控除額 = max( 旧契約だけの額, min(新 + 旧, 上限) )
上限：所得税 40,000円／住民税 28,000円
```

旧契約の上限（所得税50,000円・住民税35,000円）が併用時の上限より大きいため、
旧契約が多い場合は「旧契約だけ」が選ばれます。

**3区分の合計の上限**：所得税 **120,000円**／住民税 **70,000円**

### 2.3 地震保険料控除

```
所得税 = min( min(地震保険料, 50,000) + 旧長期分, 50,000 )
住民税 = min( ⌈min(地震保険料 × 1/2, 25,000)⌉ + 旧長期分, 25,000 )
```

旧長期損害保険料（平成18年末までの契約で満期返戻金のあるもの）：

| 支払額 | 所得税 | 住民税 |
|---|---|---|
| 〜10,000円（住民税は5,000円） | 全額 | 全額 |
| 〜20,000円（15,000円） | ⌈支払 × 1/2 + 5,000⌉ | ⌈支払 × 1/2 + 2,500⌉ |
| それ超 | 15,000円 | 10,000円 |

### 2.4 医療費控除

```
医療費控除 = ⌊ max( 0, min( 支払額 − 保険金等で補填される額
                            − min(総所得金額等 × 5％, 100,000), 2,000,000 ) ) ⌋
```

足切りは「総所得金額等の5％」と10万円の**小さいほう**。上限200万円。
セルフメディケーション税制には対応していません。

## 3. 所得税

### 3.1 課税所得金額

区分ごとに **それぞれ1,000円未満を切り捨て**ます。

```
課税総所得金額     = ⌊所得控除を引いた後の総所得金額⌋1000
課税山林所得金額   = ⌊所得控除を引いた後の山林所得金額⌋1000
課税退職所得金額   = ⌊所得控除を引いた後の退職所得金額⌋1000
分離課税の課税標準 = ⌊所得控除を引いた後の各分離所得⌋1000（種類ごとに個別）
```

### 3.2 速算表（所得税法89条）

| 課税所得金額 | 税率 | 控除額 |
|---|---|---|
| 1,949,000円まで | 5％ | 0円 |
| 3,299,000円まで | 10％ | 97,500円 |
| 6,949,000円まで | 20％ | 427,500円 |
| 8,999,000円まで | 23％ | 636,000円 |
| 17,999,000円まで | 33％ | 1,536,000円 |
| 39,999,000円まで | 40％ | 2,796,000円 |
| 40,000,000円以上 | 45％ | 4,796,000円 |

```
税額 = ⌊ 課税所得 × 税率 − 控除額 ⌋
```

### 3.3 区分ごとの税額

```
総合課税分 = 速算表(課税総所得金額)

分離課税分 = ⌊ 分離課税の課税標準 × 税率 ⌋      （種類ごとに個別に計算）

山林所得分 = 速算表( 課税山林所得金額 ÷ 5 ) × 5    ← 5分5乗方式
             ※5分の1にした額に追加の丸めはしない

退職所得分 = 速算表(課税退職所得金額)
```

### 3.4 年税額

```
税額控除前の所得税額 = 上の4つの合計
基準所得税額         = max( 0, 税額控除前の所得税額 − 税額控除 )
復興特別所得税       = ⌊ 基準所得税額 × 2.1％ ⌋
年税額               = ⌊ 基準所得税額 + 復興特別所得税 ⌋100
```

税額控除で0円になれば復興特別所得税も0円です。

## 4. 住民税

### 4.1 非課税限度額

**判定人数** ＝ 本人 1人 ＋ 同一生計配偶者 ＋ 扶養親族（**16歳未満を含む**）

```
均等割の非課税限度額 = 級地別の額 × 判定人数 + 100,000 + (判定人数2人以上なら加算額)
所得割の非課税限度額 = 350,000     × 判定人数 + 100,000 + (判定人数2人以上なら 320,000)
```

| 級地 | 1人あたり | 加算額（扶養等がいる場合） |
|---|---|---|
| 1級地 | 350,000円 | 210,000円 |
| 2級地 | 315,000円 | 189,000円 |
| 3級地 | 280,000円 | 168,000円 |

所得割は全国共通で 350,000円／320,000円 です。

**均等割と所得割で加算額が違う（21万円 対 32万円）**ため、扶養がいる世帯には
「**所得割は非課税だが均等割は課税**」という帯ができます。これがこのサイトの中心的な論点です。

**判定に使う所得が違う点にも注意**：

```
均等割の判定 … 合計所得金額（繰越控除「前」）
所得割の判定 … 総所得金額等（繰越控除「後」）
```

**特例の非課税**：障害者・未成年者・寡婦・ひとり親で**合計所得金額135万円以下**なら、
均等割・所得割とも非課税。生活扶助を受けている場合も非課税。

### 4.2 所得割

課税標準は所得税と同じく区分ごとに1,000円未満切り捨て。
ただし**退職所得は含めません**。

```
総合課税＋山林の課税標準 = ⌊総所得⌋1000 + ⌊山林⌋1000

市町村民税 = ⌊ 課税標準 × 市町村税率 ⌋      標準6％（政令指定都市は8％）
道府県民税 = ⌊ 課税標準 × 道府県税率 ⌋      標準4％（政令指定都市は2％、超過課税があれば上乗せ）
```

**分離課税分**は、按分で端数が出ないよう合計を先に確定させます。

```
合計額     = round( 課税標準 × 住民税率 )
市町村分   = ⌊ round(合計額 × 市町村の按分率 × 100) ÷ 100 ⌋
道府県分   = 合計額 − 市町村分

按分率：一般市町村 6:4（市町村0.6）／政令指定都市 8:2（市町村0.8）
```

結果として次の税率になります。

| 分離課税 | 一般市町村 | 政令指定都市 |
|---|---|---|
| 短期譲渡（合計9％） | 市5.4％＋県3.6％ | 市7.2％＋県1.8％ |
| 長期譲渡・株式等（合計5％） | 市3％＋県2％ | 市4％＋県1％ |

### 4.3 調整控除（地方税法37条）

所得税と住民税の人的控除の差を埋めるための控除です。
**合計所得金額が2,500万円を超えると適用されません。**

法律上の「合計課税所得金額」は 課税総所得金額＋課税退職所得金額＋課税山林所得金額 ですが、
住民税では退職所得を課税標準に含めない（現年分離課税で徴収済み）ため、実際には次の2つの合計です。
**分離課税の課税標準は含めません。**

```
合計課税所得金額 = 課税総所得金額 + 課税山林所得金額（＝ 4.2 の課税標準）

合計課税所得金額 ≦ 200万円 : 基礎額 = min( 人的控除の差の合計, 合計課税所得金額 )
合計課税所得金額 > 200万円 : 基礎額 = max( 人的控除の差の合計 − (合計課税所得金額 − 200万円), 50,000 )

市町村民税の調整控除 = ⌊ 基礎額 × 3％ ⌋   （政令指定都市は4％）
道府県民税の調整控除 = ⌊ 基礎額 × 2％ ⌋   （政令指定都市は1％）
```

**人的控除の差**（所得税の控除額 − 住民税の控除額 ではなく、法定の差額を使います）

| 控除 | 差額 |
|---|---|
| 基礎控除 | 50,000円（改正後も据置き） |
| 配偶者控除（一般） | 50,000／40,000／20,000円（本人の所得区分別） |
| 配偶者控除（老人） | 100,000／60,000／30,000円 |
| 配偶者特別控除 | 50,000／40,000／20,000円（配偶者の所得95万円以下）、30,000／20,000／10,000円（100万円以下）、0円（それ超） |
| 扶養控除（一般） | 50,000円 |
| 扶養控除（特定） | 180,000円 |
| 扶養控除（老人・同居老親等以外） | 100,000円 |
| 扶養控除（同居老親等） | 130,000円 |
| 障害者控除（普通） | 10,000円 |
| 障害者控除（特別） | 100,000円 |
| 障害者控除（同居特別） | 220,000円 |
| 寡婦控除 | 10,000円 |
| ひとり親控除（母） | 50,000円 |
| ひとり親控除（父） | 10,000円 |
| 勤労学生控除 | 10,000円 |
| 特定親族特別控除 | 180,000／160,000／60,000／0円（特定親族の所得区分別） |

**ひとり親控除は母5万円・父1万円で差が違います。** 控除額そのものは同じなので、
画面で「この人は母親／父親」を選ばせているのはこのためです。

### 4.4 税額控除（調整控除以外）

```
市町村分 = min( 調整控除後の市町村民税, ⌊税額控除 × 市町村の按分率⌋ )
道府県分 = min( 調整控除後の道府県民税, 税額控除 − 市町村分 )
```

ふるさと納税（寄附金税額控除）には対応していません。

### 4.5 所得割額の調整措置（地方税法附則3条の3）

所得割を課した結果、手取りが非課税限度額を下回る領域をならす措置です。

```
差額 = 所得割の非課税限度額 − ( 総所得金額等 − 所得割額 )

差額 > 0 のとき  減額分 = min( ⌊差額⌋, 所得割額 )
市町村分の減額   = ⌊ 減額分 × 市町村の所得割額 ÷ 所得割額の合計 ⌋
道府県分の減額   = 減額分 − 市町村分の減額
```

### 4.6 最終的な所得割額

```
市町村民税の所得割 = ⌊ max(0, 調整控除・税額控除・調整措置の後の額) ⌋100
道府県民税の所得割 = ⌊ max(0, 同上) ⌋100
```

**市町村分と道府県分をそれぞれ100円未満切り捨て**します。合計してから切り捨てるのではありません。

### 4.7 均等割

所得控除の影響を**まったく受けません**。非課税限度額を超えたかどうかだけで決まります。

```
市町村民税の均等割 = 3,000円（標準）
道府県民税の均等割 = 1,000円（標準）＋ 都道府県の超過課税
森林環境税（国税）  = 1,000円
```

超過課税は47都道府県すべてを公式ページと突合済みです（`node test/verify-prefectures.js`）。
均等割が非課税なら森林環境税もかかりません。

```
住民税の年税額 = 市町村民税の所得割 + 道府県民税の所得割
               + 市町村民税の均等割 + 道府県民税の均等割 + 森林環境税
```

## 5. JASSO 給付奨学金・授業料等減免の支援区分

```
支給額算定基準額 = ⌊ max( 0, 課税標準額 × 6％ − (調整控除額 + 調整額) × 係数 ) ⌋100

係数：一般市町村 1／政令指定都市 3/4
```

**課税標準額の範囲**：ここでいう課税標準額は市町村民税所得割の基礎となる金額で、
**課税総所得金額だけではありません**。分離課税の各課税所得金額（土地建物等の譲渡・
株式等の譲渡・上場株式等の配当・先物）と課税山林所得金額も合計した額を使います。
本サイトも同じ範囲（`課税総所得金額＋課税山林所得金額＋分離課税の課税標準の合計`）で計算しています。

政令指定都市は市民税の税率が8％、調整控除が4％と一般市町村と違うため、
**係数3/4を掛けて一般市町村と同じ水準に直します**。
税率は政令市でも一律6％で計算します（JASSOの算定式がそう定めているため）。

#### 所得割が0円でも基準額が0円とは限らない

市町村民税所得割が**非課税**（非課税限度額以下）の場合は、原則として支給額算定基準額は0円になり、
第Ⅰ区分になります。

ただし、**ふるさと納税（寄附金税額控除）・住宅ローン控除・定額減税・市町村民税の減免**などで
所得割「額」が0円になっているだけの場合は、課税標準額そのものは残っているため、
**支給額算定基準額は0円になりません**。

本サイトは非課税限度額で判定しており、税額控除で0円になったケースは
課税標準額から基準額を計算します（＝正しい挙動）。

#### 支援区分（生計維持者全員の基準額の合計で判定）

| 区分 | 基準額 | 給付奨学金の支給割合 |
|---|---|---|
| 第Ⅰ区分 | 100円未満 | 満額（10分の10） |
| 第Ⅱ区分 | 100円以上 25,600円未満 | 3分の2 |
| 第Ⅲ区分 | 25,600円以上 51,300円未満 | 3分の1 |
| 第Ⅳ区分 | 51,300円以上 154,500円未満 | 4分の1 |
| 区分なし | 154,500円以上 | 0円 |

**第Ⅳ区分は多子世帯（扶養する子3人以上）または私立の理工農系学科等の学生のみ**が対象です。
私立理工農系（多子世帯でない場合）は**給付奨学金は0円**で、授業料等減免のみ（文系との差額に着目した額）。

#### 154,500円以上でも、多子世帯は授業料等減免の対象

**多子世帯は令和7年度から「所得制限なく」授業料等減免を受けられます。**
そのため基準額が154,500円以上で支援区分から外れても、

- **授業料等減免 … 対象**（上限額まで。所得制限なし）
- **給付奨学金 … 0円**（支援区分に応じた額のため）

となります。本サイトも「授業料等減免のみ対象（給付奨学金は0円）」と表示します。
多子世帯でない場合は、154,500円以上は減免も給付も対象外です。

> 出典：JASSO「多子世帯支援について」—「多子世帯に属している学生等は**所得制限なく**
> 授業料等減免を受けられるようになりました」／「給付奨学金は支援区分（第1〜4区分）に応じた金額が支給されます」

## 6. 国民健康保険料の軽減判定

このサイトが出すのは**軽減割合（7割・5割・2割・なし）だけ**です。
保険料率は市区町村ごとに違うため、保険料額そのものは計算しません。

**軽減の対象は均等割額と平等割額です。所得割額は軽減されません。** 申請は不要です。

### 6.1 軽減判定所得の作り方

7割・5割・2割の判定は、**税法上の「合計所得金額」そのものではなく、国保の「軽減判定所得」**で行います。
名前が似ていて紛らわしいので、この資料では一貫して「軽減判定所得」と呼びます。

- 基礎控除・社会保険料控除などの**所得控除は差し引きません**
- 純損失・雑損失・上場株式等の譲渡損失などの**繰越控除がある場合は、控除した後**の額で判定します
- 実体は「**総所得金額等の合計**（＝繰越控除後）」に、下の調整を加えたものです

住民税の所得と**扱いが違う**のがポイントです。

| 項目 | 軽減判定での扱い |
|---|---|
| 所得控除（基礎控除・社会保険料控除など） | **差し引かない** |
| 退職所得（一時金） | **含めない** |
| 純損失・雑損失の繰越控除 | **適用した後**の額 |
| 65歳以上の公的年金等に係る所得 | さらに **150,000円**を控除（所得の額が上限） |
| 土地建物等の分離譲渡所得 | **特別控除前**の額（住民税の所得割は特別控除後なので逆） |
| 事業専従者控除・青色事業専従者給与 | **事業主の所得に戻す**（専従者側の所得は0とみなす） |

```
1人分の判定所得 = max( 0, 総所得金額等 − 退職所得 − (65歳以上なら min(150,000, 年金雑所得)) )

世帯の判定所得 = 世帯主（擬制世帯主を含む）＋ 被保険者 ＋ 特定同一世帯所属者 の合計
               + 分離譲渡の特別控除額（足し戻し）
               + 事業専従者控除額・青色事業専従者給与（足し戻し）
```

**擬制世帯主**：世帯主が会社の健康保険でも、世帯に国保加入者がいれば
**世帯主の所得は軽減判定に含めます**。ただし均等割の人数には入りません。

#### 株式・先物などを申告するかどうかで結果が変わります

| 選んだ申告方法 | 国保の軽減判定所得 |
|---|---|
| 源泉徴収ありの特定口座で**申告不要**を選んだ上場株式等の譲渡所得・配当所得 | **含まれません**（申告していないので所得に入らない） |
| **確定申告した**場合 | **含まれます**。損益通算・繰越控除を適用した**後**の金額が反映されます |

つまり「確定申告して繰越控除を使うと所得税・住民税は下がるが、国保の判定所得には申告した分が乗る」
という関係になります。逆に申告不要を選べば国保には影響しません。
**本サイトの分離課税の欄は「確定申告する分」を入れる欄**です。申告不要にするものは入力しないでください。

#### 土地建物等の譲渡所得は「特別控除前」で判定します

| 場面 | 使う金額 |
|---|---|
| 所得税・住民税の税額計算 | 特別控除（3,000万円特別控除など）を**引いた後**の譲渡所得 |
| 国保の軽減判定 | 特別控除を**引く前**の金額 |

本サイトの入力ルールはこうです。

1. STEP 4〜6 の「土地建物等の譲渡所得」には、**特別控除後**の金額を入れる（税額計算用）
2. STEP 7 の「分離譲渡所得の特別控除額の合計」に、**引いた特別控除額**を入れる（国保用に足し戻す）

2 を入れ忘れると、国保の軽減判定所得が実際より小さく出ます。

### 6.2 軽減の基準額（令和8年度）

```
被保険者等の数 = 国保の被保険者 ＋ 特定同一世帯所属者

7割軽減 : 430,000円 + 100,000円 × (給与所得者等の数 − 1)
5割軽減 : 430,000円 + 310,000円 × 被保険者等の数 + 100,000円 × (給与所得者等の数 − 1)
2割軽減 : 430,000円 + 570,000円 × 被保険者等の数 + 100,000円 × (給与所得者等の数 − 1)
```

世帯の判定所得がこの額**以下**なら該当します（7割から順に判定）。
給与所得者等が1人以下なら加算はありません。

**給与所得者等**：給与収入55万円超の方＋公的年金収入60万円超（65歳未満）／125万円超（65歳以上）の方。

**国保に「被扶養者」はありません。** 加入者は一人ひとりが被保険者で、
子どもも赤ちゃんも1人として数えます。1人少なく数えると5割・2割の基準額が
310,000円・570,000円ずつ下がり、受けられる軽減が出なくなります。
